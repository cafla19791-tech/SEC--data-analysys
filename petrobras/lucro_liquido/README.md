# Lucro líquido Petrobras 2002–2025

Série anual do lucro líquido consolidado atribuível aos acionistas da Petrobras.

| Arquivo | Conteúdo |
|---|---|
| `petrobras_lucro_liquido_2002_2025.xlsx` | Planilha (aba `lucro_liquido` + `notas`) |
| `petrobras_lucro_liquido_2002_2025.md` | Tabela markdown |
| `petrobras_lucro_liquido_2002_2025.csv` / `.json` | Dados tabulares |

## Fontes

- **R$ 2002–2008:** releases/RMF/DFP BR GAAP arquivados na SEC (Form 6-K).
- **R$ 2009–2025:** CVM DFP consolidada, conta 3.11.01.
- **US$:** Form 20-F (Selected Financial Data / DRE) e SEC CompanyFacts (IFRS).

As séries em R$ e US$ não são conversões cambiais simples (normas e momentos de publicação diferem).
